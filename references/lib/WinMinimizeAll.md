# WinMinimizeAll / WinMinimizeAllUndo

Minimizes or unminimizes all windows.

```ahk
WinMinimizeAll
WinMinimizeAllUndo
```

On most systems, this is equivalent to Explorer's `Win`+`M` and `Win`+`D` hotkeys.

## Examples

```ahk

```
